使い方と注意事項

基本操作

  1. 「写真を選択」またはDrag & DropでJPEG / PNG / WebPを追加します。
  2. 追加した写真は並べ替えでき、不要な写真は削除して元に戻せます。
  3. 配置を選んだ後、写真の見せ方とキャンバスの比率・余白・背景・角丸を調整できます。
  4. スマートフォンでは下部の「写真 / 配置 / 仕上げ / 保存」で画面を切り替えます。
  5. Ctrl / Cmd + Zで元に戻し、Ctrl / Cmd + Shift + Zでやり直せます。プレビューにフォーカスすると矢印キーで写真位置を調整できます。

プライバシー

読み込んだ写真はブラウザー内で処理され、このアプリから外部サーバーへ送信されません。ランタイム通信も行いません。

注意事項

  • 写真や編集内容はブラウザーへ自動保存しません。ページを再読み込みすると現在の作業は失われます。
  • 一度に扱える写真は20枚までです。
  • JPEG / PNG / WebPで保存できます。透明背景はPNGでのみ利用できます。出力画像には元写真のEXIF / GPSを引き継ぎません。

対応形式: JPEG / PNG / WebP。ファイルは端末内だけで処理します。
